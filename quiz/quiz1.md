# Storybookクイズ

## Q1. Storybookの最初の名前は？

2016年に公開された当初、Storybookは何という名前だったでしょう？

- A. React Storybook
- B. Kadira Stories
- C. React Styleguidist
- D. Component Workshop

<details>
<summary>ヒント</summary>

最初は特定のライブラリ専用のツールでした。

</details>

<details>
<summary>正解と解説</summary>

**正解：A. React Storybook**

StorybookはKadira社が2016年に「React Storybook」として公開しました。当初はReact専用でしたが、2017年にコミュニティへ移管され、VueやReact Nativeなどにも対応した際に、名前も単に「Storybook」になりました。

なお「React Styleguidist」は、Storybookとは別に実在するコンポーネント開発ツールです。

</details>
